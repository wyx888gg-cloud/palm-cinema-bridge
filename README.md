# Palm City Twitch Bridge

Twitch Player-only bridge for Palm City FiveM world screens.

Bridge URL after GitHub Pages is enabled:

`https://wyx888gg-cloud.github.io/palm-cinema-bridge/twitch_bridge.html`

Example:

`https://wyx888gg-cloud.github.io/palm-cinema-bridge/twitch_bridge.html?channel=xqc&muted=1`

This page uses the current HTTPS hostname automatically as the Twitch `parent` value.
